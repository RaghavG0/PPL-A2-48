```text
I am implementing S2 of the attached PPL Assignment 2 in Racket using #lang racket/base. Work only on the helper functions my-length and my-map.
```

### Prompt 2 — Direct recursive `insert-if-short`

```text
Here is my current S2 Racket file containing my-length and my-map. Work only on a first, direct implementation of insert-if-short(x, lst, n).

It must recursively process every nested list and insert x at the front of each list whose ORIGINAL top-level length is less than n. Determine the length before insertion. Empty lists are eligible when 0 < n. The top-level list is treated exactly like nested lists.

Use only the assignment's permitted built-ins. Do not implement make-inserter or print-insert-result, and do not keep multiple competing definitions of insert-if-short in the final file. Return a minimal patch and walk through the assignment's nested-list examples.
```

### Prompt 3 — Read input and print the result

```text
Continue with my current S2 file. Work only on print-insert-result.
```

### Prompt 4 — Higher-order `make-inserter` and final definition

```text
Here is my current S2 Racket file. Work only on S2.c.

Implement (make-inserter x len-ok?) so it returns a function accepting a list. That returned function must recursively process nested lists and insert x at the front of every list whose ORIGINAL length satisfies len-ok?. Then redefine insert-if-short using make-inserter and the predicate (< len n).

The final file must contain exactly one definition of insert-if-short, the one implemented through make-inserter. Preserve the existing my-length, my-map, and print-insert-result behavior. Use only allowed built-ins; do not use mutation or forbidden list functions. Explain how you ensure the predicate is applied to the original list length, not the transformed length.
```
